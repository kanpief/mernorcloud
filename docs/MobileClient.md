# 📱 Mobile Client Guide / Hướng dẫn Client di động

Hướng dẫn kết nối và sử dụng ứng dụng di động cho MernorCloud (Zpiltk Edition).  
Guide explaining how to connect and use the mobile client app for MernorCloud (Zpiltk Edition).

---

## 🇻🇳 Tiếng Việt

### 1. Giới thiệu Client di động

MernorCloud hỗ trợ giao diện web tối ưu cho di động (PWA) và tích hợp các ứng dụng client chuyên dụng.
Giao diện được thiết kế mượt mà cho màn hình cảm ứng, hỗ trợ:
- Phát nhạc và video chạy nền trên trình duyệt di động.
- Đọc sách điện tử EPUB, xem tài liệu PDF và truyện tranh CBZ offline.
- Tải lên ảnh, video trực tiếp từ thư viện điện thoại.

---

### 2. Cách kết nối với Server của bạn

1. **Chuẩn bị tên miền Server**: Đảm bảo máy chủ MernorCloud của bạn được thiết lập tên miền riêng hỗ trợ kết nối bảo mật HTTPS (ví dụ qua Cloudflare Tunnel hoặc Nginx: `https://cloud.tenmien-cua-ban.com`).
2. **Nhập URL máy chủ**: Khi mở ứng dụng hoặc truy cập qua web mobile, điền đầy đủ địa chỉ HTTPS của máy chủ vào ô **Server URL**.
3. **Đăng nhập**: Sử dụng tài khoản đăng nhập (Admin hoặc tài khoản phụ) đã được tạo trên hệ thống.
4. **Trải nghiệm**: Hệ thống tự động ghi nhớ phiên đăng nhập cho các lần truy cập tiếp theo.

## 🇺🇸 English

### 1. Introduction to Mobile Client

MernorCloud provides a responsive mobile interface (PWA) and client integration tailored for smartphones and tablets:
- Background audio/video streaming.
- Built-in reader for EPUB, PDF, and CBZ comics.
- Direct media uploads from your camera roll.

---

### 2. How to Connect to Your Server

1. **Server Domain**: Ensure your server is accessible via a secure HTTPS domain (e.g., using Cloudflare Tunnel or a reverse proxy).
2. **Enter Server URL**: Input your full HTTPS server address into the **Server URL** prompt.
3. **Login**: Authenticate with your existing user credentials.
4. **Enjoy**: Your session and server settings will be saved for seamless future access.
